Tips for Best Results:

  • Provider Selection: Pollinations works immediately, Edge TTS requires backend setup
  • Pollinations Voices: Amy and Emma work great for mature female narratives
  • Edge Voices: Jenny or Sara work exceptionally well for storytelling (when backend is available)
  • Speed: Keep between 0.8x - 1.0x for storytelling (default 1.0x recommended)
  • Text Length: Pollinations handles up to ~5000 characters per request, will auto-chunk longer texts
  • Large Scripts: For 10,000+ word scripts, processing will be done in chunks and combined
  • File Format: Downloads as high-quality audio suitable for YouTube
